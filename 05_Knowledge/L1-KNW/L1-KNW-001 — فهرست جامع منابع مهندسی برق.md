# L1-KNW-001 — فهرست جامع منابع مهندسی برق

## ۰. خلاصه اجرایی و راهنمای اتوماسیون

این نود، **مرجع رسمی و ماشین‌خوان منابع** شرکت Xennic است. هدف آن فراهم کردن داده‌های ساختاریافته برای **Hermes** (از طریق MCP Server) و **n8n** (از طریق HTTP Request و AI Agent) جهت تولید خودکار نودهای مرتبط، آپلود منابع به Open Notebook، و مدیریت چرخه به‌روزرسانی است.

**دستورالعمل برای Hermes/n8n:**
- داده‌های منابع در بخش **«داده‌های ساختاریافته (JSON)»** قرار دارد.
- هر آیتم شامل `id`, `title`, `category`, `priority`, `notebook_target`, `resource_type`, `access_type`, `status` و `linked_nodes` است.
- برای تولید نود جدید از یک منبع، از `id` به‌عنوان پیشوند و از `linked_nodes` برای ایجاد ارجاعات استفاده کنید.
- منابع با `status: "pending"` در اولویت آپلود به Open Notebook قرار دارند.

## ۲. دستورالعمل برای Hermes (MCP Server)

**هدف:** تولید نودهای جدید بر اساس منابع موجود.

**گام‌ها:**  
۱. از ابزار `obsidian_read_note` برای خواندن این نود استفاده کنید.  
۲. بخش «داده‌های ساختاریافته (JSON)» را استخراج کنید.  
۳. برای هر منبع با `status: "pending"`، یک نود جدید با شناسه `[[RES-...]]` ایجاد کنید.  
۴. در نود جدید، فیلدهای `linked_nodes` را به‌عنوان ارجاعات درج کنید.  
۵. وضعیت منبع را به `"processed"` تغییر دهید و نود جدید را با ابزار `obsidian_save_note` ذخیره کنید.

**مثال (Hermes Prompt):**

```text
بر اساس نود L1-KNW-001، برای منبع RES-STD-001 (IEC 60364) یک نود جدید با عنوان «IEC 60364 — تأسیسات الکتریکی فشار ضعیف» ایجاد کن. این نود باید به L2-TEC-001 و FND-007 ارجاع دهد. از قالب node-template.md استفاده کن.
```

## ۳. دستورالعمل برای n8n (اتوماسیون)

**هدف:** آپلود خودکار منابع به Open Notebook و تولید گزارش.

**Workflow پیشنهادی:**  
۱. **Trigger:** Cron (روزانه).  
۲. **HTTP Request:** دریافت نود از Obsidian Local REST API (`GET /vault/05_Knowledge/L1-KNW/L1-KNW-001...`).  
۳. **Code Node:** استخراج JSON از بخش «داده‌های ساختاریافته».  
۴. **Loop:** برای هر منبع با `status: "pending"`:

- **HTTP Request:** آپلود فایل به Open Notebook (`POST /api/sources`).
    
- **Set Node:** به‌روزرسانی وضعیت به `"processed"`.  
    ۵. **HTTP Request:** به‌روزرسانی نود در Obsidian با وضعیت‌های جدید.  
    ۶. **Email/Telegram:** ارسال گزارش روزانه.
    

**نکته:** برای اتصال n8n به Obsidian، از `http://host.docker.internal:27124` (در Docker Desktop) استفاده کنید .[](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest/common-issues)
