# ZNNY-Xennic-Vault

**مخزن دانش، راهبرد و مستندات رسمی شرکت سهامی خاص زر نور نیرو یکتا (برند تجاری: Xennic)**

این مخزن یک **Obsidian Vault** ساختاریافته است که به‌عنوان تک‌مرجع حقیقت (Single Source of Truth) برای هویت سازمانی، راهبرد، عملیات و معماری فنی شرکت زر نور نیرو یکتا — فعال در حوزه خدمات مهندسی برق قدرت، انرژی‌های نو و توسعه پلتفرم هوشمند **Xennic** — استفاده می‌شود.

## 🎯 این مخزن چیست؟

هر موضوع مهم شرکت (حقوقی، برند، مالی، بازار، فنی، عملیاتی) به‌صورت یک **نود مستقل Markdown** با شناسه یکتا (`NODE-ID`)، frontmatter استاندارد و ساختار ثابت (هدف، محتوا، ارجاعات، Changelog) مستند می‌شود. تمام تغییرات از طریق Git و Pull Request مدیریت می‌شوند تا تاریخچه تصمیم‌ها قابل ردیابی و حسابرسی باشد.

## 📜 قواعد توسعه

تمام قواعد نام‌گذاری، ساختار نود، Git Flow، و فرایند PR در سند مرجع زیر مستند شده است و **مطالعه آن پیش از هر مشارکتی الزامی است**:

➡️ [`00_Meta/Conventions/META-CONV-001 — قواعد توسعه پروژه.md`](<./00_Meta/Conventions/META-CONV-001 — قواعد توسعه پروژه.md>)

خلاصه فشرده:
- هیچ کامیتی مستقیم روی `main` یا `dev` انجام نمی‌شود؛ همه تغییرات از طریق Pull Request.
- هر شاخه فقط یک نود/تغییر مشخص را پوشش می‌دهد.
- پیام کامیت و عنوان PR به انگلیسی و با الگوی `<type>(<NODE-ID>): <description>` نوشته می‌شود.
- هیچ نودی مستقیم `approved` نمی‌شود؛ مسیر وضعیت: `draft → review → approved → archived`.
- فایل‌ها UTF-8 بدون BOM هستند؛ frontmatter همیشه در خط اول فایل قرار دارد.
- ضمیمه‌ها (PDF، لوگو، تصاویر حجیم) در Open Notebook نگهداری می‌شوند، نه در Git.

## 🏗️ وضعیت فعلی

- **لایه‌های تکمیل‌شده**: Founder، PreLaunch (راهبرد/برند/حقوقی/مالی/بازار)، Launch (عملیات/خدمات/بازاریابی/امنیت/پلتفرم).
- **پروژه‌های آزمایشی (Pilot) در دست طراحی**: وب‌سایت حرفه‌ای شرکتی، سامانه هوشمند مدیریت انرژی، سامانه هوشمند تأمین و فروش تجهیزات برق — همگی ذیل معماری کلان [`META-INT-080`](<./00_Meta/Integration/META-INT-080 — معماری کلان سیستم‌عامل هوشمند سازمانی Xennic.md>).
- **لایه آینده (L3 / Future)**: هنوز آغاز نشده است.
