# کارت ویزیت — رو و پشت

> [!abstract] خلاصه
> نسخهٔ نهاییِ **پرشده**ی کارت ویزیت بر پایهٔ قالب خالی کیت ست اداری: با لوگوی رسمی، نام، سمت، تلفن، دو ایمیل و نشانی وب‌سایت.
> ابعاد ۸۵×۵۵ میلی‌متر (استاندارد کارت)، بلید ۳ میلی‌متر، علائم برش در فایل چاپی، تمام متن‌ها **به مسیر برداری تبدیل شده‌اند** تا در هیچ سیستمی جابه‌جا نشوند.
> پشت کارت یک **QR واقعی** به نشانی `https://xennic.ir` دارد.

## ۵. بازتولید فایل

```bash
cd _src
npm pack vazirmatn && tar xzf vazirmatn-*.tgz      # فونت (یک‌بار)
export VAZIRMATN_DIR=$PWD/package/fonts/ttf
python3 build_card.py        # ← svg/ را می‌سازد
python3 presentation.py      # ← تختهٔ ارائه
npm i sharp && node render.mjs   # ← png/ را می‌سازد
```

متن‌ها در بالای `build_card.py` به‌صورت ثابت‌های `TXT_…` تعریف شده‌اند؛ برای ویرایش محتوا فقط همان‌ها را تغییر دهید.
