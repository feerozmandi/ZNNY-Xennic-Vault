# Changelog — Xennic Preview Gate `1.1.2`

## نسخهٔ جاری: `1.1.2` — اصلاحات پس از بازبینی ایستای دستیار وبسایت

این نسخه برای رفع دو نقص قطعی گزارش‌شده در بازبینی ایستای v1.1.1 ساخته شد؛ به‌معنای پذیرش آزمون یکپارچه یا تأیید اجرا نیست. **نسخه‌های `1.1.1` و `1.1.0` `SUPERSEDED / DO NOT RUN` هستند.** نسخهٔ 1.1.2 نیز فقط برای بازبینی است و هنوز تأیید اجرای محلی/عملیاتی ندارد.

### موارد اصلاح‌شده

- **Runbook migration:** `::text` از query حذف شد تا `psql -At` مقدار boolean به‌شکل `t`/`f` چاپ کند و با `test "$MIGRATION_OK" = t` ناسازگار نباشد. توضیح خروجی نیز به‌روزرسانی شد. Query در این بسته اجرا نشده است.
- **Payload media upload:** metadata فرم اکنون در `_payload` به‌صورت JSON فرستاده می‌شود، نه در field جداگانهٔ `alt`.
- **PNG fixture:** دادهٔ 1x1 RGBA با CRC معتبر برای همهٔ chunkها و IDAT zlib stream معتبر جایگزین fixture قبلی شد.
- **Payload media retrieval:** انتظار URL به مسیر `/api/media/file/...` تغییر کرد؛ همان مسیر برای retrieval با gate معتبر و denial بدون gate استفاده می‌شود.
- **Caddy mock:** مسیر `/api/media/file/synthetic.png` بدون gate باید در API gate با 401 رد شود.
- اصلاحات قبلی logout/Bearer، login تازه، Cookie mock و `/api/graphql` حفظ شده‌اند.

### فایل‌های اصلاح‌شده داخل package

- OAuth واقعی و egress gate به GitHub در overlay stub/internal بررسی نمی‌شود.

## اولویت ۲ — Payload media form/route

- `test_payload_caddy.mjs` — multipart اکنون `_payload` JSON با `alt`، فایل `file` با PNG مصنوعی معتبر، و مسیر `/api/media/file/...` را به‌کار می‌برد. بازیابی metadata و bytes، و denial بدون gate، هر دو در کد تست هستند؛ اجرا نشده‌اند.
- PNG fixture — بررسی byte/chunk/CRC/zlib ایستا شده؛ لطفاً format و Payload upload contract را با نسخهٔ دقیق baseline بازبینی کنید.
- `test_caddy_mock.py` — endpoint `/api/media/file/synthetic.png` بدون gate باید 401 بگیرد؛ mock test اجرا نشده است.
- endpoint ایجاد/بازیابی رسانه در Payload baseline و URL تولیدشده از `PREVIEW_ORIGIN` را با source دقیق تطبیق دهید؛ هیچ پاسخ status runtime فرض نشده است.

## اولویت ۳ — اصلاحات حفظ‌شده از v1.1.1

- Payload `3.91.0` logout/Bearer: `sid` لغوشده، `/api/staff/me` با انتظار `HTTP 200` و `user:null`، و login تازه برای درخواست‌های بعدی.

## اولویت ۴ — blockerهای runtime هنوز باز

لطفاً هر مورد را «تأیید»، «نیازمند اصلاح» یا «نامعلوم» علامت بزنید:

1. آیا Compose merge در نسخهٔ موردنیاز به‌طور واقعی پورت مستقیم app را حذف می‌کند؟ آیا bypass در IPv4/IPv6 یا host routing باقی می‌ماند؟
2. آیا gate واقعی باید به GitHub egress داشته باشد و چه allowlistی لازم است؟ overlay فعلی gate stub و network `internal: true` دارد و هیچ OAuth/GitHub egress واقعی را نمی‌آزماید.
3. آیا image digestهای Caddy/Python از registry و platform درست‌اند؟ Node/Postgres digest pin ندارند.
4. آیا `_payload` + `file` دقیقاً form contract نسخهٔ Payload `3.91.0` است و upload response مسیر `/api/media/file/{filename}` می‌دهد؟ لطفاً فقط با source/pinned docs تطبیق دهید؛ endpoint اجرا نشود.
5. آیا query migration خام boolean در psql `-At` مطابق `t/f` چاپ می‌کند؟ query اجرا نشده است؛ اگر جایگزین مطمئن‌تری لازم است، گزارش کنید.
6. آیا source-level logout/session finding و HTTP `200 user:null` برای همین نسخهٔ Payload معتبر است؟ Token `401` فرض نشود.

```sh
CADDY_BIN=/path/to/caddy-2.11.7 python3 test_caddy_mock.py
CADDY_BIN=/path/to/caddy-2.11.7 python3 check_caddy_config.py
```

Caddy config و تست در این تحویل اجرا نشده‌اند. اگر Caddy از نسخهٔ دقیق دیگری است یا خطا داد، توقف کنید؛ فایل‌های live را تغییر ندهید و log خام را ارسال نکنید.

## مرحلهٔ چهار — Payload واقعی روی محیط disposable (فقط پس از رفع blockerها و مجوز صریح)

این بخش فقط یک **برنامهٔ آتی** است و اکنون نباید اجرا شود. از checkout دقیق وبسایت استفاده کنید؛ فایل `compose.preview.yml` داخل بسته را برای build استفاده نکنید، چون build context باید خود checkout وبسایت باشد. overlay فعلی gate مصنوعی دارد، نه OAuth واقعی.

### A. کنترل project تازه و آماده‌سازی بی‌اثر بر داده

۱. مطمئن شوید checkout دقیق baseline و `compose.preview.yml` آن موجود است. پیش از شروع، فهرست project/volumeها را بخوانید؛ هیچ volume موجود را باز، reuse یا حذف نکنید:

```sh
docker compose ls --all
docker volume ls --filter label=com.docker.compose.project=xennic-preview-gate-payload-lab
```

اگر project/volume با این نام وجود دارد، توقف کنید؛ `down -v` یا پاک‌سازی انجام ندهید. DB باید تازه و مستقل باشد.

۲. پس از بررسی image digestها، Compose merge، port isolation و تأیید مالک، فایل env تصادفی فقط برای محیط disposable بسازید:

```sh
python3 /path/to/v1.1.2/prepare_payload_lab_env.py
```

این helper در `~/.config/xennic-preview-gate-delivery/payload-lab.env` مقادیر تصادفی را با mode `0600` می‌سازد و آن‌ها را چاپ نمی‌کند؛ اگر فایل از قبل هست، آن را overwrite نکنید. `.env.preview.example` فقط placeholder است و نباید source یا به Compose داده شود. `LAB_DIR` جداگانه باید مسیر مطلق پوشهٔ استخراج‌شدهٔ v1.1.2 باشد.

۳. در ریشهٔ checkout، ابتدا فقط Compose را بدون چاپ envها اعتبارسنجی کنید. خروجی `config` را بدون `--quiet` اجرا/ارسال نکنید:

```sh
BUNDLE=/absolute/path/to/xennic-preview-gate-delivery-2026-10-31-v1.1.2
ENV_FILE="$HOME/.config/xennic-preview-gate-delivery/payload-lab.env"
LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" config --quiet
```

اگر Compose نسخهٔ لازم را ندارد، `!reset` parse نمی‌شود، `config --quiet` خطا می‌دهد، یا port/network مؤثر با انتظار فرق دارد، توقف کنید. حتی موفقیت این فرمان هنوز blockerهای runtime را رفع نمی‌کند.

۴. build فقط پس از تأیید provenance/digestها و مجوز:

```sh
LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" build app
```

### B. ترتیب اجباری DB تازه: readiness → migration → verification → Staff bootstrap → seed

ترتیب زیر الزامی است. هر خطا یا خروجی نامنتظره به معنی **توقف کامل** است؛ migration ناموفق یا نامطمئن یعنی app، Staff bootstrap و seed را شروع نکنید.

۵. فقط PostgreSQL را start کنید و تا healthcheck `pg_isready` سالم نشود ادامه ندهید. `--wait` باید سرویس را تا healthy نگه دارد/منتظر بماند:

```sh
LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" \
  up -d --wait postgres
```

۶. migration را صریحاً یک‌بار به‌صورت one-shot اجرا کنید؛ migration خودکار در startup انجام نمی‌شود:

```sh
LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" \
  run --rm --no-deps app npm run preview:migrate
```

دستور باید exit code صفر بدهد و wrapper پیام `Preview migration completed.` چاپ کند. اگر دستور خطا داد، پیام عمومی خطاست، ledger غایب است، baseline ناقص است یا خروجی نامعلوم است: **توقف**؛ `app`, Staff bootstrap و seed را اجرا نکنید. خطاهای خام DB/connection string را به اشتراک نگذارید.

۷. پس از exit code صفر، DB را با query فقط‌خواندنی دوباره بررسی کنید. query باید دقیقاً `t` چاپ کند؛ `f`، خطا، خروجی اضافی یا خالی یعنی توقف:

```sh
MIGRATION_OK=$(LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" \
  exec -T postgres sh -lc 'psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Atc "SELECT (to_regclass('\''website.payload_migrations'\'') IS NOT NULL AND to_regclass('\''shared.customers'\'') IS NOT NULL AND EXISTS (SELECT 1 FROM website.payload_migrations WHERE name = '\''20261030_163225_baseline'\'' AND batch >= 0) AND NOT EXISTS (SELECT 1 FROM website.payload_migrations WHERE batch = -1));')
test "$MIGRATION_OK" = t || { echo 'Migration verification failed; stop before app, Staff, or seed.'; exit 1; }
```

این query یک boolean خام PostgreSQL برمی‌گرداند؛ با `psql -At` خروجی `t`/`f` است و عمداً `::text` ندارد (که `true`/`false` چاپ می‌کرد و با شرط shell برابر `t` ناسازگار بود). فقط وجود migration ledger، ثبت baseline با batch غیرمنفی، نبود schema-push batch `-1` و وجود `shared.customers` کنترل می‌شود؛ schema کامل/قابلیت restore ثابت نمی‌شود. wrapper `preview:migrate` نیز این baselineها را بررسی می‌کند.

۸. فقط اگر migration و query هر دو موفق‌اند، app و Caddy و **gate stub** را در همان project محدود شروع کنید. اجرای این فرمان به blockerهای بالا و مجوز جدید وابسته است:

```sh
LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" \
  up -d --wait app caddy gate
```

Caddy روی `127.0.0.1:443` در نظر گرفته شده؛ app، Postgres و gate نباید host port داشته باشند. این رفتار هنوز با Compose merge یا `docker ps` runtime تأیید نشده است. اگر port mapping یا bind غیرمنتظره دیدید، آزمون را متوقف کنید. `gate_stub.py` احراز هویت یا identity نیست؛ هر process محلی می‌تواند marker مصنوعی را بفرستد. این مرحله فقط آزمایش disposable است، نه bootstrap امن حساب واقعی.

### C. یک‌بار Staff آزمایشی و آزمون API؛ سپس یک‌بار seed

۹. پس از سالم‌شدن app، CA عمومی Caddy را فقط به مسیر خصوصی محلی برای client آزمایش کپی کنید؛ private key را کپی نکنید:

```sh
CID=$(LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" ps -q caddy)
test -n "$CID" || { echo 'Caddy container not found; stop.'; exit 1; }
docker cp "$CID:/data/caddy/pki/authorities/local/root.crt" \
  "$HOME/.config/xennic-preview-gate-delivery/lab-root.crt"
```

۱۰. آزمون `test_payload_caddy.mjs` با `LAB_CA_FILE`، host mapping فقط در resolver همان Node process، gate marker مصنوعی و یک Staff تصادفی `example.invalid` اجرا شود:

```sh
LAB_CA_FILE="$HOME/.config/xennic-preview-gate-delivery/lab-root.crt" \
  node "$BUNDLE/test_payload_caddy.mjs"
```

این آزمون یک Staff مصنوعی را از first-register می‌سازد، logout می‌کند، Bearer قبلی را با انتظار درست `HTTP 200` و `user:null` می‌سنجد، برای آزمون‌های بعدی login تازه می‌گیرد، GraphQL را با/بدون gate می‌سنجد، سپس PNG تصادفی را با gate و Payload Staff می‌نویسد و metadata/bytes را با و بدون gate می‌خواند. هیچ حساب واقعی یا دادهٔ مشتری استفاده نشود. اگر پس از first-register آزمون شکست خورد، حساب bootstrap‌شده باقی می‌ماند؛ first-register را روی همان DB دوباره اجرا نکنید، DB/volume را پاک نکنید و seed را شروع نکنید. توقف و بررسی لازم است.

**مرز bootstrap امن:** مرحلهٔ بالا فقط Staff مصنوعی در lab loopback است؛ gate stub هویت یا امنیت واقعی ندارد و هر process محلی می‌تواند marker آن را جعل کند. از آن برای حساب واقعی/مالک استفاده نکنید. bootstrap واقعی خارج از این بسته است و تا وقتی gate واقعی بازبینی‌شده، حذف و آزمون عدم‌دسترسی پورت مستقیم app، مسیر local/tunnel مجاز، و تحویل credential از کانال امنِ مورد تأیید مالک تعیین نشده، نباید انجام شود. در آن فرایند credential واقعی هرگز در Git، log یا چت قرار نگیرد و first-register فقط یک بار روی DB تازه و حفاظت‌شده انجام شود.

۱۱. فقط اگر آزمون کامل موفق شد، seed سایت را **یک‌بار** در همان DB تازه اجرا کنید:

```sh
LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
  -f compose.preview.yml -f "$BUNDLE/compose.payload-lab.override.yml" \
  run --rm --no-deps app npm run preview:seed
```

پیش‌شرط‌ها: migration query برابر `t`، baseline معتبر، Staff آزمایشی bootstrap شده و integration test موفق. wrapper advisory lock برای جلوگیری از اجرای هم‌زمان دارد و seed کدهای محتوایی موجود را overwrite نمی‌کند؛ با این حال ledger دائمی «seed انجام شد» ندارد. بنابراین پس از موفقیت دوباره اجرا نکنید. اگر seed exit غیرصفر داد، خودکار retry نکنید؛ محتوا/DB را بازبینی و تصمیم جدا بگیرید. این seed محتوای preview مصوب سایت است؛ writeهای خود integration test همچنان فقط Staff و فایل PNG مصنوعی هستند.

### D. توقف

پس از تست موفق، فقط project یکتای همین lab را بدون حذف volume متوقف کنید:

```sh
LAB_DIR="$BUNDLE" docker compose --env-file "$ENV_FILE" \
  -p xennic-preview-gate-payload-lab \
```

func (p *GitHubProvider) getOrgs(ctx context.Context, s *sessions.SessionState) error {

	type Organization struct {
		// Support for Github organizations
		// https://docs.github.com/en/rest/orgs/orgs#list-organizations-for-the-authenticated-user
		Login string `json:"login,omitempty"`
		// Support for Gitea organizations
		// https://docs.gitea.com/api/1.24/#tag/organization/operation/orgGetAll
		Name string `json:"name,omitempty"`
	}

	pn := 1
	for {
		params := url.Values{
			"per_page": {"100"},
			"page":     {strconv.Itoa(pn)},
		}

		endpoint := p.makeGitHubAPIEndpoint("/user/orgs", &params)

		var orgs []Organization
		err := requests.New(endpoint.String()).
			WithContext(ctx).
			WithHeaders(makeGitHubHeader(s.AccessToken)).
			Do().
			UnmarshalInto(&orgs)
		if err != nil {
			return err
		}

		if len(orgs) == 0 {
			break
		}

		for _, org := range orgs {
			var orgName string
			if len(org.Login) > 0 {
				orgName = org.Login
				logger.Printf("Member of Github Organization: %q", orgName)
			} else {
				orgName = org.Name
				logger.Printf("Member of Gitea Organization: %q", orgName)
			}

			s.Groups = append(s.Groups, orgName)
		}
		pn++
	}

	return nil
}

func (p *GitHubProvider) checkRestrictions(ctx context.Context, s *sessions.SessionState) error {
	// If a user is verified by username options, skip the following restrictions
	if ok, err := p.checkUserRestriction(ctx, s); err != nil || ok {
		return err
	}

	var err error
	switch {
	case p.Org != "" && p.Team != "":
		err = p.hasOrgAndTeam(s)
	case p.Org != "":
		err = p.hasOrg(s)
	case p.Team != "":
		err = p.hasTeam(s)
	}

	if err != nil {
		return err
	}

	if p.Org == "" && p.Repo != "" && p.Token == "" {
		// If we have a token we'll do the collaborator check
		return p.hasRepoAccess(ctx, s.AccessToken)
	}

	return nil
}

func (p *GitHubProvider) checkUserRestriction(ctx context.Context, s *sessions.SessionState) (bool, error) {
	if len(p.Users) == 0 {
		return false, nil
	}

	verifiedUser, err := p.hasUser(ctx, s.AccessToken)
	if err != nil {
		return verifiedUser, err
	}

	// org and repository options are not configured
	if !verifiedUser && p.Org == "" && p.Repo == "" {
		return false, errors.New("missing github user")
	}

	return verifiedUser, nil
}

func (p *GitHubProvider) hasUser(ctx context.Context, accessToken string) (bool, error) {
	// https://developer.github.com/v3/users/#get-the-authenticated-user

	var user struct {
		Login string `json:"login"`
		Email string `json:"email"`
	}

	endpoint := p.makeGitHubAPIEndpoint("/user", nil)

	err := requests.New(endpoint.String()).
		WithContext(ctx).
		WithHeaders(makeGitHubHeader(accessToken)).
		Do().
		UnmarshalInto(&user)
	if err != nil {
		return false, err
	}

	if p.isVerifiedUser(user.Login) {
		return true, nil
	}
	return false, nil
}

func (p *GitHubProvider) isVerifiedUser(username string) bool {
	for _, u := range p.Users {
		if username == u {
			return true
		}
	}
	return false
}

func (p *GitHubProvider) getEmail(ctx context.Context, s *sessions.SessionState) error {

	var emails []struct {
		Email    string `json:"email"`
		Primary  bool   `json:"primary"`
		Verified bool   `json:"verified"`
	}

	endpoint := p.makeGitHubAPIEndpoint("/user/emails", nil)

	err := requests.New(endpoint.String()).
		WithContext(ctx).
		WithHeaders(makeGitHubHeader(s.AccessToken)).
		Do().
		UnmarshalInto(&emails)
	if err != nil {
		return err
	}

	for _, email := range emails {
		if email.Verified {
			if email.Primary {
				s.Email = email.Email
				return nil
			}
		}
	}

	return nil
}

func (p *GitHubProvider) getUser(ctx context.Context, s *sessions.SessionState) error {
	var user struct {
		Login string `json:"login"`
		Email string `json:"email"`
	}

	endpoint := p.makeGitHubAPIEndpoint("/user", nil)

	err := requests.New(endpoint.String()).
		WithContext(ctx).
		WithHeaders(makeGitHubHeader(s.AccessToken)).
		Do().
		UnmarshalInto(&user)
	if err != nil {
		return err
	}

	// Now that we have the username we can check collaborator status
	if !p.isVerifiedUser(user.Login) && p.Org == "" && p.Repo != "" && p.Token != "" {
		if ok, err := p.isCollaborator(ctx, user.Login, p.Token); err != nil || !ok {
			return err
		}

// NewGitHubProvider initiates a new GitHubProvider
func NewGitHubProvider(p *ProviderData, opts options.GitHubOptions) *GitHubProvider {
	p.setProviderDefaults(providerDefaults{
		name:        githubProviderName,
		loginURL:    githubDefaultLoginURL,

		validateURL: githubDefaultValidateURL,

func makeGitHubHeader(accessToken string) http.Header {
	// extra headers required by the GitHub API when making authenticated requests
	extraHeaders := map[string]string{
		acceptHeader: "application/vnd.github.v3+json",
	}
	return makeAuthorizationHeader(tokenTypeToken, accessToken, extraHeaders)
}

func (p *GitHubProvider) makeGitHubAPIEndpoint(endpoint string, params *url.Values) *url.URL {
	basePath := p.ValidateURL.Path

	re := regexp.MustCompile(`^/api/v\d+`)
	match := re.FindString(p.ValidateURL.Path)
	if match != "" {
		basePath = match
	}

	if params == nil {
		params = &url.Values{}
	}

	return &url.URL{
		Scheme:   p.ValidateURL.Scheme,
		Host:     p.ValidateURL.Host,
		Path:     path.Join(basePath, endpoint),
		RawQuery: params.Encode(),
	}
}

func (p *GitHubProvider) hasOrg(s *sessions.SessionState) error {
	// https://developer.github.com/v3/orgs/#list-your-organizations
	var orgs []string

	for _, group := range s.Groups {
		if !strings.Contains(group, ":") {
			orgs = append(orgs, group)
		}
	}

	presentOrgs := make([]string, 0, len(orgs))
	for _, org := range orgs {
		if p.Org == org {
			logger.Printf("Found Github Organization:%q", org)
			return nil
		}
		presentOrgs = append(presentOrgs, org)
	}

	logger.Printf("Missing Organization:%q in %v", p.Org, presentOrgs)
	return errors.New("user is missing required organization")
}

func (p *GitHubProvider) hasOrgAndTeam(s *sessions.SessionState) error {
	type orgTeam struct {
		Org  string `json:"org"`
		Team string `json:"team"`
	}

	var presentOrgTeams []orgTeam

	for _, group := range s.Groups {
		if strings.Contains(group, orgTeamSeparator) {
			ot := strings.Split(group, orgTeamSeparator)
			presentOrgTeams = append(presentOrgTeams, orgTeam{ot[0], ot[1]})
		}
	}

	var hasOrg bool

	presentOrgs := make(map[string]bool)
	var presentTeams []string

	for _, ot := range presentOrgTeams {
		presentOrgs[ot.Org] = true

		if strings.EqualFold(p.Org, ot.Org) {
			hasOrg = true

			teams := strings.Split(p.Team, ",")
			for _, team := range teams {
				if strings.EqualFold(strings.TrimSpace(team), ot.Team) {
					logger.Printf("Found Github Organization/Team:%q/%q", ot.Org, ot.Team)
					return nil
				}
			}
			presentTeams = append(presentTeams, ot.Team)
		}
	}

	if hasOrg {
		logger.Printf("Missing Team:%q from Org:%q in teams: %v", p.Team, p.Org, presentTeams)
		return errors.New("user is missing required team")
	}

	logger.Printf("Missing Organization:%q in %#v", p.Org, maps.Keys(presentOrgs))
	return errors.New("user is missing required organization")
}

func (p *GitHubProvider) hasTeam(s *sessions.SessionState) error {
	var teams []string

	for _, group := range s.Groups {
		if strings.Contains(group, orgTeamSeparator) {
			teams = append(teams, strings.TrimSpace(group))
		}
	}

	var presentTeams = make([]string, 0, len(teams))

	for _, ot := range teams {
		allowedTeams := strings.Split(p.Team, ",")
		for _, team := range allowedTeams {
			if !strings.Contains(team, orgTeamSeparator) {
				logger.Printf("Please use fully qualified team names (org:team-slug) if you omit the organisation. Current Team name: %s", team)
				return errors.New("team name is invalid")
			}

			if strings.EqualFold(strings.TrimSpace(team), ot) {
				logger.Printf("Found Github Organization/Team:%s", ot)
				return nil
			}
		}
		presentTeams = append(presentTeams, ot)
	}

	logger.Printf("Missing Team:%q in teams: %v", p.Team, presentTeams)
	return errors.New("user is missing required team")
}

func (p *GitHubProvider) hasRepoAccess(ctx context.Context, accessToken string) error {
	// https://developer.github.com/v3/repos/#get-a-repository

	type permissions struct {
		Pull bool `json:"pull"`
		Push bool `json:"push"`
	}

	type repository struct {
		Permissions permissions `json:"permissions"`
		Private     bool        `json:"private"`
	}

	endpoint := p.makeGitHubAPIEndpoint("/repos/"+p.Repo, nil)

	var repo repository
	err := requests.New(endpoint.String()).
		WithContext(ctx).
		WithHeaders(makeGitHubHeader(accessToken)).
		Do().
		UnmarshalInto(&repo)

	if err != nil {
		return err
	}

	// Every user can implicitly pull from a public repo, so only grant access
	// if they have push access or the repo is private and they can pull
	if repo.Permissions.Push || (repo.Private && repo.Permissions.Pull) {
		return nil
	}

	return errors.New("user doesn't have repository access")
}

func (p *GitHubProvider) hasUser(ctx context.Context, accessToken string) (bool, error) {
	// https://developer.github.com/v3/users/#get-the-authenticated-user

	var user struct {
		Login string `json:"login"`
		Email string `json:"email"`
	}

	endpoint := p.makeGitHubAPIEndpoint("/user", nil)

	err := requests.New(endpoint.String()).
		WithContext(ctx).
		WithHeaders(makeGitHubHeader(accessToken)).
		Do().
		UnmarshalInto(&user)
	if err != nil {
		return false, err
	}

	if p.isVerifiedUser(user.Login) {
		return true, nil
	}
	return false, nil
}

func (p *GitHubProvider) isCollaborator(ctx context.Context, username, accessToken string) (bool, error) {
	//https://developer.github.com/v3/repos/collaborators/#check-if-a-user-is-a-collaborator

	endpoint := p.makeGitHubAPIEndpoint("/repos/"+p.Repo+"/collaborators/"+username, nil)
	result := requests.New(endpoint.String()).
		WithContext(ctx).
		WithHeaders(makeGitHubHeader(accessToken)).
		Do()
	if result.Error() != nil {
		return false, result.Error()
	}

	if result.StatusCode() != 204 {
		return false, fmt.Errorf("got %d from %q %s",
			result.StatusCode(), endpoint.String(), result.Body())
	}

	logger.Printf("got %d from %q %s", result.StatusCode(), endpoint.String(), result.Body())

	return true, nil
}

// getEmail updates the SessionState Email
func (p *GitHubProvider) getEmail(ctx context.Context, s *sessions.SessionState) error {

	var emails []struct {
		Email    string `json:"email"`
		Primary  bool   `json:"primary"`
		Verified bool   `json:"verified"`
	}

	endpoint := p.makeGitHubAPIEndpoint("/user/emails", nil)

		WithContext(ctx).
		WithHeaders(makeGitHubHeader(s.AccessToken)).
		Do().
		UnmarshalInto(&emails)
	if err != nil {
		return err

	for _, email := range emails {

// getUser updates the SessionState User
func (p *GitHubProvider) getUser(ctx context.Context, s *sessions.SessionState) error {
	var user struct {
		Login string `json:"login"`
		Email string `json:"email"`
	}

	endpoint := p.makeGitHubAPIEndpoint("/user", nil)

	err := requests.New(endpoint.String()).
		WithContext(ctx).
		WithHeaders(makeGitHubHeader(s.AccessToken)).
		Do().
		UnmarshalInto(&user)
	if err != nil {
		return err
	}

	// Now that we have the username we can check collaborator status
	if !p.isVerifiedUser(user.Login) && p.Org == "" && p.Repo != "" && p.Token != "" {
		if ok, err := p.isCollaborator(ctx, user.Login, p.Token); err != nil || !ok {
			return err
		}
	}

	s.User = user.Login
	return nil
}

func (p *GitHubProvider) isVerifiedUser(username string) bool {
	for _, u := range p.Users {
		if username == u {
			return true
		}
	}
	return false
}

func (p *GitHubProvider) checkRestrictions(ctx context.Context, s *sessions.SessionState) error {
	// If a user is verified by username options, skip the following restrictions
	if ok, err := p.checkUserRestriction(ctx, s); err != nil || ok {
		return err
	}

	var err error
	switch {
	case p.Org != "" && p.Team != "":
		err = p.hasOrgAndTeam(s)
	case p.Org != "":
		err = p.hasOrg(s)
	case p.Team != "":
		err = p.hasTeam(s)
	}

	if err != nil {
		return err
	}

	if p.Org == "" && p.Repo != "" && p.Token == "" {
		// If we have a token we'll do the collaborator check
		return p.hasRepoAccess(ctx, s.AccessToken)
	}

	return nil
}

func (p *GitHubProvider) checkUserRestriction(ctx context.Context, s *sessions.SessionState) (bool, error) {
	if len(p.Users) == 0 {
		return false, nil
	}

	verifiedUser, err := p.hasUser(ctx, s.AccessToken)
	if err != nil {
		return verifiedUser, err
	}

	// org and repository options are not configured
	if !verifiedUser && p.Org == "" && p.Repo == "" {
		return false, errors.New("missing github user")
	}

	return verifiedUser, nil
}

function request(path, {method='GET', body, headers={}, withGate=true}={}) {
  return new Promise((resolve, reject) => {
    const outgoing = {Host:hostname, ...headers}
    if (withGate) outgoing.Cookie = [gateCookie, outgoing.Cookie].filter(Boolean).join('; ')
    if (body !== undefined) outgoing['Content-Length'] = Buffer.isBuffer(body) ? body.length : Buffer.byteLength(body)
    const req = https.request({hostname, servername:hostname, port:443, path, method, headers:outgoing,
      ca, rejectUnauthorized:true,
      lookup(_host, options, cb) {
        if (options?.all) cb(null, [{address:'127.0.0.1', family:4}])
        else cb(null, '127.0.0.1', 4)
      },
    }, res => {
      const chunks=[]
      res.on('data', c => chunks.push(c))
      res.on('end', () => resolve({status:res.statusCode, headers:res.headers, body:Buffer.concat(chunks)}))
    })
    req.on('error', reject)
    if (body !== undefined) req.write(body)
    req.end()
  })
}

  check(/(?:^|;)\s*Path=\/(?:;|$)/i.test(setCookie), 'Payload cookie Path=/')
  check(!/(?:^|;)\s*Domain=/i.test(setCookie), 'Payload cookie host-only')
