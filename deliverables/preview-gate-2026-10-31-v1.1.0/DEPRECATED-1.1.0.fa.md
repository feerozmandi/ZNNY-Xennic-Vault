# اعلان رسمی deprecation — Xennic Preview Gate 1.1.0

## `SUPERSEDED / DO NOT RUN / برای اجرا ممنوع`

نسخهٔ `1.1.0` با نسخهٔ بازبینی‌شدهٔ `1.1.1` superseded شده است. **هیچ فایل، ZIP یا دستور نسخهٔ 1.1.0 را اجرا، deploy، apply یا برای تغییر زیرساخت استفاده نکنید.** نسخهٔ 1.1.1 نیز فعلاً صرفاً برای بازبینی است و تا رفع blockerها و تأیید صریح مالک مجوز اجرا ندارد.

فایل‌های ZIP/TXT و checksumهای 1.1.0 عمداً به‌صورت تاریخی و تغییرنیافته حفظ شده‌اند تا hashهای قبلی معتبر بمانند. این اعلان بیرون از آرشیو قدیمی است؛ اگر قبلاً 1.1.0 را دانلود کرده‌اید، فایل‌هایش را اجرا نکنید و برای بازبینی به [تحویل 1.1.1](./README-v1.1.1.fa.md) مراجعه کنید.

هیچ نسخه‌ای از این تحویل برای VPS، DNS، gate فعال یا محیط عملیاتی تأیید نشده است. Stack یکپارچه تا پایان بازبینی مجدد و مجوز جداگانه اجرا نشود.
