# اعلان deprecation — Xennic Preview Gate 1.1.1

## `SUPERSEDED / DO NOT RUN / نسخهٔ بازبینی جدیدتر: 1.1.2`

نسخهٔ `1.1.1` با `1.1.2` superseded شده است. **فایل‌ها، ZIP، TXT و checksumهای 1.1.1 را اجرا، deploy، apply یا برای تغییر زیرساخت استفاده نکنید.** بازبینی ایستای وبسایت دو نقص در migration-check و media test یافت؛ نسخهٔ جدید آن‌ها را اصلاح می‌کند، اما runtime هنوز بررسی نشده است.

فایل‌های 1.1.1 و checksumهایشان برای سابقه بدون تغییر نگهداری می‌شوند. اگر آن نسخه را دریافت کرده‌اید، از آن اجرا نکنید و [تحویل 1.1.2](./README-v1.1.2.fa.md) را برای بازبینی بخوانید. نسخهٔ 1.1.2 هم مجوز اجرا نیست؛ digestها، Compose مؤثر، bypass پورت و egress واقعی هنوز blocker هستند.

هیچ نسخه‌ای از این تحویل برای VPS، DNS، gate فعال یا محیط عملیاتی تأیید نشده است. تا بازبینی مجدد و مجوز صریح مالک stack اجرا نشود.
