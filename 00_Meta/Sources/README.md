# 00_Meta/Sources — منابع خام استنادی

این پوشه محل نگهداری **اسناد خام منبع** (Raw Source Documents) است که توسط یک یا چند نود Obsidian به‌عنوان مرجع استناد شده‌اند، اما خودشان یک نود رسمی (با قالب NODE-ID، frontmatter و ساختار Why/Content/References/Changelog) نیستند.

## تفاوت با نودها
- فایل‌های این پوشه **جایگزین نودهای ساختاریافته نمی‌شوند**؛ محتوای مهم و تصمیم‌های نهایی باید در نودهای رسمی مربوطه (`01_Founder`, `02_PreLaunch`, `03_Launch`, `00_Meta/Integration`) مستند شوند.
- این پوشه برای حفظ **سند مرجع اصلی** نگهداری می‌شود تا در صورت نیاز به بازبینی یا استخراج محتوای بیشتر، منبع اولیه در دسترس باشد.
- ارجاع نودها به فایل‌های این پوشه از طریق Wiki-Link با نام کامل فایل انجام می‌شود (Obsidian بر اساس نام فایل، نه مسیر، لینک را حل می‌کند).
