### ۵.۶. استراتژی Multi-Model AI

Xennic از **چند مدل زبانی مختلف** استفاده می‌کند:

| کاربرد | مدل اصلی | جایگزین |
|---|---|---|
| تولید متن | ChatGPT | Claude |
| تحلیل عمیق | Claude | GPT-4 |
| کد | Claude/GPT-4 | DeepSeek |
| تحقیق | Gemini | ChatGPT |
| ترجمه | DeepL | ChatGPT |
| Vision | GPT-4 Vision | Claude Vision |
| صوت | Whisper | Gemini |
| تصویر | Midjourney | DALL-E |
| ویدیو | HeyGen | Runway |
| صدا | ElevenLabs | Azure TTS |
| مدل محلی | Ollama | — |

**استراتژی Fallback**:

ChatGPT → Claude → Gemini → Ollama


**مزایا**:
- عدم وابستگی به یک ارائه‌دهنده
- بهترین نتیجه از هر مدل
- Fallback خودکار
- کاهش هزینه

**نکته**: در Prompt Library، برای هر Prompt، مدل پیشنهادی ذکر می‌شود.
