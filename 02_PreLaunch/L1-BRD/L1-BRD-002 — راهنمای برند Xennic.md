# L1-BRD-002 — راهنمای برند Xennic (Brand Guideline)

## ۱. هدف (Why)
راهنمای عملیاتی برای استفاده یکپارچه از برند Xennic در تمام نقاط تماس. این نود:
- راهنمای عملیاتی برای تیم طراحی
- تضمین یکپارچگی برند در همه نقاط تماس
- مرجع رسمی برای شرکا و پیمانکاران
- پایه طراحی پلتفرم Xennic

**رابطه با L1-BRD-001**:
- L1-BRD-001: هویت برند (فلسفه، استراتژی، اصول)
- L1-BRD-002: راهنمای برند (جزئیات فنی، عملیاتی)
